# Paperclip agent instructions

**Three files to install. One per agent.** No shared skill index, extra agent instruction files, or copied upstream skills.

Start with [the 2-minute setup guide](paperclip-agent-instructions/README.md). The three ready-to-paste files are:

- [Coordinator](paperclip-agent-instructions/coordinator/AGENTS.md)
- [Senior UI Developer](paperclip-agent-instructions/senior-ui-developer/AGENTS.md)
- [Code Reviewer](paperclip-agent-instructions/code-reviewer/AGENTS.md)

Skills come from [Matt Pocock's repository](https://github.com/mattpocock/skills) and are installed/attached in Paperclip, **not** copied into these files. Each AGENTS.md directly tells its role when to use an attached skill.
