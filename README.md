# Paperclip agent instruction pack

**Keep Paperclip's three files per agent:** `AGENTS.md`, `HEARTBEAT.md`, and `SOUL.md`.

See the [quick installation guide](paperclip-agent-instructions/README.md) and the three role folders:

- [Coordinator](paperclip-agent-instructions/coordinator/)
- [Senior UI Developer](paperclip-agent-instructions/senior-ui-developer/)
- [Code Reviewer](paperclip-agent-instructions/code-reviewer/)

Each `AGENTS.md` contains the Matt Pocock skill index and triggers for its role. Import the actual skills from [mattpocock/skills](https://github.com/mattpocock/skills) into Paperclip once and attach them to the relevant agents. No separate `MATT_POCOCK_SKILLS.md` is needed.
